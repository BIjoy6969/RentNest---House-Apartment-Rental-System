# 🏠 RentNest – House & Apartment Rental System

RentNest is a full-stack web-based house and apartment rental management system developed using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
The platform simplifies the rental process by enabling landlords to manage property listings and tenants to browse, book, and apply for rentals online.

## 📖 Project Overview

RentNest provides a digital solution to traditional rental systems by eliminating manual paperwork and improving communication between landlords and tenants.  
The system follows **MVC architecture** and is designed to be responsive, scalable, and user-friendly.

---

## ✨ Features

### 🏘️ Property Management
- View all available properties
- Detailed property information (title, address, rent, availability)
- Search and filter by:
  - Location
  - Rent range
  - Bedrooms

### 👤 User Roles
- **Tenant**
- **Landlord**
- **Admin**
- Role-based dashboards and access control

### 📅 Viewing Booking System
- Tenants can request property viewings
- Landlords can approve or reject requests

### 📝 Rental Application
- Structured rental application form
- Application status tracking:
  - Pending
  - Approved
  - Rejected

### ❤️ Wishlist
- Tenants can add or remove properties from wishlist

### 💬 Messaging System
- In-app messaging between landlords and tenants

### 🛠️ Admin Panel
- Manage users
- Manage properties
- Handle complaints and flagged content

---

## 🚀 Non-Functional Requirements
